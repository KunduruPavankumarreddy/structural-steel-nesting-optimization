## Proposal summary

The recommendation is to establish a reliable material-utilisation baseline, compare manual nesting with the existing StruMIS automatic nesting feature on matched jobs, and only build a constraint-aware optimisation layer if benchmarking shows a measurable gap. Any pilot keeps engineer approval before production release.

The proposal treats savings as unverified until supported by client data. Cost and effort figures are planning assumptions, not supplier quotations or measured customer outcomes.
